# 前端控制台（web/）

一个零依赖的本地 Node 服务 + 单页应用，用来在手机上查看和有限度地干预这台 Windows 机器上的 NapCat 机器人。
它不是保活系统的一部分：**删掉 `web/` 不会影响 guardian、qrsync 或 AstrBot 的任何行为**。

## 1. 边界

| 做 | 不做 |
| --- | --- |
| 只读 `metrics.json` / `login-state.json` / `astrbot-state.json` / `tunnel-state.json` / `kick.log` / 三份日志尾部 | 不写任何生产状态文件（唯一例外是受保护动作转交的 flag） |
| 二维码、被踢历史、健康状态、日志检索 | 不直接杀进程、不改 NapCat / AstrBot 配置 |
| 四个受保护动作：重启 worker、触发通知自检、`Start-ScheduledTask`、全量重启（写 `force-relaunch.flag`） | 不做登录、不解密、不落库 |

## 2. 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/?k=<key>` | 单文件页（内联 CSS/JS/图标 + 首屏状态与二维码） |
| GET | `/api/status` | 聚合状态：guardian / login / napcat / astrbot / tunnel / qr / metrics |
| GET | `/api/kicks` | `kick.log` 解析后的被踢记录 |
| GET | `/api/logs?name=guardian\|astrbot\|daemon&lines=200` | 日志尾部（只读最后 N 行） |
| GET | `/api/qr.png` | 当前二维码（`no-store`，按 mtime 加 cache-buster） |
| GET | `/api/stream` | **SSE**：状态变化才推，二维码变化时带 data URI |
| POST | `/api/actions` | 受保护动作，body 需 `confirm` 字段与该动作的确认词一致 |

鉴权：`?k=` 首次访问会种一个 HttpOnly cookie；之后也可用 `X-QR-Key` 头。比较用 `crypto.timingSafeEqual`，错 key 一律 404，不区分"不存在"和"无权限"。

## 3. 安全设计

- **动作必须二次确认**：页面弹窗要求手工输入确认词，服务端再校验一次，避免误点或 CSRF（同源 + 自定义头）。
- **限频**：每个动作每 60 秒最多 3 次，写入 `actions.log`（谁、何时、什么动作、结果）。
- **不暴露敏感信息**：输出前对 QQ 号、邮箱、token、完整出口 IP 做掩码；源码里没有任何密钥。
- **CSP**：`img-src 'self' data:`、`style-src 'self' 'unsafe-inline'`（内联样式）、`script-src 'nonce-<每请求随机>'`；同一响应里注入的 script 带 nonce，手写内联脚本会被拦。

## 4. 性能（2026-11-17 改造）

公网经 ngrok 一次往返 0.3–1.4 s，弱网手机上原来的 4 请求 + 3 秒轮询体感很差。改造后：

| 指标 | 改前 | 改后 |
| --- | --- | --- |
| 首屏请求数 | 4 | **1** |
| 首屏传输 | ~51 KB | **18.2 KB**（gzip） |
| 二维码 | 打开后再取 | 内联 data URI，首屏即见 |
| 打开后网络活动 | 20 次/分轮询 | **0**，状态变化才推 |

实现：`buildInlinePage(nonce)` 内联三件资源并注入 `window.__BOOT__`；`send()` 按 `Accept-Encoding` 自动 gzip；`/api/stream` 用 SSE（服务端 2 秒比对指纹，变化才发 `data:`，每 20 秒一个 `: keep-alive`）。

## 5. 部署

```powershell
# 1) 复制配置模板并改成自己的
Copy-Item web\config.example.json web\config.json
notepad web\config.json      # key / port / napcatHome

# 2) 前台跑一次看是否正常
node web\server.js

# 3) 常驻（互斥体防双开 + 崩溃退避重启），可放进启动文件夹
powershell -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File <repo>\web\start-console.ps1
```

公网暴露：与 qrsync 共用一条隧道最省事 —— 在 `qrsync/config.json` 写
`"publicPort": 8440, "publicHealthPath": "/api/status"`，`daemon.ps1` 就会把隧道指到面板，健康检查也改用面板的 `/api/status`。

## 6. 排障

| 现象 | 处理 |
| --- | --- |
| 打开是白页、控制台报 CSP | 别在 `index.html` 手写内联 script；逻辑放 `public/app.js` |
| `?k=` 错 → 404 | 正常；key 在 `web/config.json` 或启动日志里 |
| SSE 不更新、但刷新后正常 | 反代/隧道缓冲了流；确认 `Content-Type: text/event-stream`、`Cache-Control: no-store` 未被改写 |
| 手机上是 ngrok 拦截页 | 点一次 Visit Site（会种 cookie），微信内置浏览器通常不行，换系统浏览器 |
