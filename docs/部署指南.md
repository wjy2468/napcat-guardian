# 部署指南（小白版）

本指南假设你已经能让 NapCat + AstrBot 正常跑起来（扫码登录、机器人能回消息），只是想让它"挂得稳、不被踢、掉了能自愈"。

---

## 一、准备工作

### 1. 确认目录结构

以本方案为例（路径可以不同，但建议纯英文、无空格）：

```
D:\napcat\NapCat.Shell\        # NapCat 程序目录
C:\Users\你的用户名\qq-deepseek-bot\astrbot\   # AstrBot 目录
D:\napcat-guardian\            # 本仓库（守护脚本）
```

### 2. 确认 NapCat 已开启本地 HTTP API

守护脚本要通过本地 HTTP API（默认 `http://127.0.0.1:3000`）来发保活消息和检测状态。

方法：把 `config/napcat/onebot11.example.json` 复制到 NapCat 的 `config/` 目录，改名为：

```
onebot11_<你的机器人QQ号>.json
```

例如机器人 QQ 是 `123456789`，就命名为 `onebot11_123456789.json`。

里面包含：

- 一个 HTTP Server（`127.0.0.1:3000`）；
- 一个反向 WebSocket 客户端，连到 AstrBot（`ws://127.0.0.1:6199/ws`）。

重启 NapCat 后，浏览器或命令行访问 `http://127.0.0.1:3000/get_status` 应能返回数据。

### 3. 拿到 NapCat WebUI token

打开 NapCat 的 `config/webui.json`，找到：

```json
"token": "xxxxxxxx"
```

这个 token 守护脚本要用，先记下来。

---

## 二、配置守护脚本

打开 `scripts/guardian.ps1`，找到顶部 `Configuration` 区，逐项填写：

```powershell
# 机器人 QQ 号
$QQ_UIN     = "123456789"

# 你自己的管理员 QQ 号
$ADMIN_UIN  = "987654321"

# NapCat / AstrBot 目录
$NAPCAT_DIR = "D:\napcat\NapCat.Shell"
$ASTRBOT_DIR  = "C:\Users\你的用户名\qq-deepseek-bot\astrbot"

# Python 解释器（用你实际安装的、且装好依赖的那个）
$PYTHON_EXE   = "C:\Users\你的用户名\AppData\Local\Programs\Python\Python314\python.exe"

# 上一步拿到的 WebUI token
$WEBUI_TOK  = "xxxxxxxx"

# 日志路径（默认即可）
$LOG_FILE   = "D:\napcat\guardian.log"
```

> 如果你不需要 ffmpeg，把 `$FFMPEG_BIN` 设为 `""`。

---

## 三、安装为计划任务

**右键** `scripts/install_guardian.bat` → **以管理员身份运行**。

它会自动提权并调用 `install_guardian.ps1`，完成：

1. 注册计划任务 `NapCatGuardian`；
2. 设置为：登录时启动、最高权限、隐藏窗口、失败自动重启；
3. 立即启动。

看到 `Install complete. Guardian is running ...` 即成功。

### 验证

打开 PowerShell，执行：

```powershell
Get-ScheduledTask -TaskName NapCatGuardian
```

`State` 应为 `Running`。

等待一个保活周期（10–17 分钟），查看 `guardian.log`，出现：

```
keep-alive sent: 19:30  ok
```

说明保活已经在工作。

---

## 四、（可选）修复 WiFi 网络

如果你的电脑用 WiFi 挂机，建议执行一次：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\network_fix.ps1
```

（右键以管理员身份运行）

它会：

1. 关闭网卡"允许空闲时关闭以省电"；
2. 无线适配器调到最高性能；
3. 重启网卡（**会断网几秒**，属正常现象）。

> 长期挂机最稳的方案是**插网线**。

---

## 五、卸载

如果想取消守护：

```powershell
Unregister-ScheduledTask -TaskName NapCatGuardian -Confirm:$false
```

---

## 六、验证整体效果

| 检查项 | 期望结果 |
|--------|----------|
| `Get-ScheduledTask NapCatGuardian` | `Running` |
| `guardian.log` 中 `keep-alive sent` | 每 10–17 分钟一条 |
| 机器人空闲超过 23 分钟 | 仍然在线，不再被踢 |
| 手动让机器人断网几秒后恢复 | 守护脚本自动检测、自愈 |
| 登录态彻底失效 | 弹窗提示扫码 |
